GmailのPDF荷物情報をGeminiで抽出し、Telegram送信まで自動化した物流会社のワークフロー

事業者：Imona Logistics / Joseph Asinyo
業種：物流・トラック輸送のディスパッチ業務
規模：記事から確認できません

今回の事例

手作業でPDFを開き、荷物情報を転記して、チャットへ送る――この一連の作業が毎回10分かかっていました。Imona Logisticsでは、ブローカーから届くPDFをもとにしたディスパッチ業務をAIと自動化ツールでつなぎ、転記作業を大幅に短縮した事例です。記事では、Gemini AIにPDFから必要項目を抽出させ、その結果をTelegramのディスパッチグループへ流す流れが紹介されています。

どんな課題があったのか

記事で確認できる導入前の課題は、ブローカーからGmailで届くPDFを人が開き、荷物情報をコピーして整形し、Telegramのディスパッチグループへ送る作業が毎回発生していたことです。1件あたり約10分かかり、1日20件超を処理していたため、月80時間以上が手作業に消えていました。PDFのレイアウトが毎回少しずつ違い、必要情報を見つけて転記する負荷が高かったことも課題です。

AIをどう活用したのか

入力

→ Gmailで受信したブローカーのPDF

AIによる処理

→ Gemini AIがPDFから必要な荷物情報を抽出

→ 抽出対象は、記事で確認できる範囲では pickup / delivery address、pickup / delivery date、rate、mileage など

→ 著者は、どの項目を抜き出すか、通常どこにあるか、どの形式で返すかをプロンプトで教え込んだと説明している

次のシステム・処理

→ 抽出結果をディスパッチ用の後続処理へ渡す

→ Telegramのディスパッチグループへ送信

出力

→ 受け取った荷物情報を整理した状態でTelegramに共有

人間による確認・最終作業

→ 記事からは、誰がどの段階で最終確認するかの詳細は確認できません

→ ただし、AIが誤ると誤った情報共有や配送遅延につながるため、最終的な運用では人の確認が重要であることは記事から読み取れます

補足

→ この事例のAI担当は、分類よりも「抽出」が中心です

→ PDFごとのレイアウト差に対して、試行錯誤でプロンプトを調整し、複数の実ファイルで精度を高めたとされています

どんな効果があったのか

記事で確認できる効果は、手作業の10分/件が数秒に短縮されたこと、月80時間の削減、3か月以上運用して精度が安定していることです。著者の計算では、10分削減 × 1日20件 × 週6日で月80時間の削減になります。売上増加や人員削減の有無は記事から確認できません。

なぜこのAI活用が有効だったのか

このワークフローが機能した理由は、PDFから取り出す項目を固定し、出力形式も明確にしたうえで、実ファイルを使ってプロンプトを繰り返し調整した点にあると考えられます。AIに自由な要約をさせるのではなく、必要なフィールドだけを抽出させたことで、後続のTelegram共有にそのまま使える形へ寄せられました。これは分析であり、記事本文の直接記述ではありません。

この事例から学べること

1. AIは“賢く読む”より“決まった項目を抜く”用途で安定しやすい。

2. 入力ファイルの形式がばらばらでも、抽出項目を固定すると自動化しやすい。

3. AIの出力先を最初から決めると、手作業の残りが減る。

4. 精度が重要な業務ほど、最初から完全自動ではなく、人の確認を前提に設計したほうが安全。

5. 実データで何度も試し、プロンプトを育てる工程が品質を左右する。

自分で作るなら？・どう応用できる？

自分で作るなら、次のような流れが考えられます。

1. GmailやDropbox、Google DriveからPDFや添付ファイルを取得する

2. Python、Google Apps Script、Zapier、MakeなどでファイルをAIへ渡す

3. ChatGPT APIやOpenAI API、Geminiで必要項目を抽出する

4. 抽出結果をGoogle Sheets、Excel、Notion、Airtable、DBに保存する

5. Slack、Teams、メール、Telegramで担当者へ通知する

6. 人間が最終確認して、確定情報として使う

仕事への応用例

- 物流・配送: 受信した見積書や配送依頼PDFから、住所・日時・金額・数量だけを抜き出してスプレッドシートへ記録し、担当者へ通知する

- 営業事務: 取引先メール添付の注文書PDFから、会社名・品目・納期・数量を抽出して受注管理表に自動入力する

- 現場管理: 点検報告書PDFから、異常箇所・対応期限・担当者を抜き出してタスク管理ツールに送る

- カスタマーサポート: 問い合わせメールの本文と添付を読み、種類ごとに分類して担当チームへ振り分ける

プライベート応用例

- 旅行計画: 予約メールやPDFから、便名・日程・ホテル名を抜き出してカレンダーに登録する

- 家計管理: 明細PDFや領収書画像から、支出日・金額・店名を抽出して家計簿に入れる

- 書類整理: 保険証券や契約書のPDFから、更新日・契約先・連絡先を抜き出して一覧化する
