今回の事例

手作業でMediumの投稿実績を確認し、月次向けの要約を書き、次にやることを整理するのが面倒だったため、著者は自分用の自動化ワークフローを作りました。使ったのはPython＋BeautifulSoup、OpenAI API、Notion連携の3つです。結果として、投稿データの取得から要約、次のタスク作成までを一続きの流れに変えています。

どんな課題があったのか

記事で確認できる課題は、Mediumのダッシュボードを見ながら投稿ごとの閲覧数や反応を手で追い、週次の報告をまとめ、次の行動を考える作業が繰り返し発生していたことです。著者はこれを「退屈で反復的」と表現しており、毎週1時間かかるはずの作業をもっと短くしたいと考えていました。MediumのAPIアクセスが十分ではなかったため、必要なデータを自前で取りに行く必要もありました。

AIをどう活用したのか

入力

- Mediumダッシュボードから取得した投稿実績データ（閲覧数、読了数、拍手数など）

- その週の投稿一覧と各指標を整理したデータ

↓

AIによる処理

- OpenAI APIで、整理済みデータをもとに週次サマリーを生成

- 単なる数値の羅列ではなく、「どのテーマやタイトルが伸びたか」といった示唆を文章化

- 著者の例では、"Python系タイトルがAI系より38%良い"のような実用的な示唆を出したと書かれています

↓

次のシステム・処理

- PythonからNotion APIへ連携

- AI要約の内容をもとに、次回の行動タスクをNotionへ登録

↓

出力

- 週次パフォーマンス要約

- 次にやるべきタスク一覧

- これらが日常の管理システム（Notion）に入る

↓

人間による確認・最終作業

補足

- Python + BeautifulSoupは、スクレイピングと整形担当

- OpenAI APIは、要約・洞察抽出担当

- Notionは、アクション化と記録担当

どんな効果があったのか

金額や売上増加は記事から確認できません。確認できる効果は、手作業の削減、毎週のレポート作成時間の短縮、投稿傾向の見落とし防止、そして要約からタスク作成までを一連の流れにできたことです。著者は、全体のループが単一コマンドで20秒未満で動くと述べています。

なぜこのAI活用が有効だったのか

このワークフローが有効だった理由は、分析対象のデータを先に整形してからAIに渡している点にあります。記事内でも、Rawな数値のままChatGPTに分析させるのではなく、構造化されたリストにしてから渡すべきだと述べています。これは分析の質を上げやすい設計です。また、要約で終わらず、Notionに次のタスクを自動登録することで、洞察がそのまま行動に変わる構造になっています。

この事例から学べること

- AIは『考える部分』に使い、取得や整形はPythonのような処理系で分担すると設計しやすい

- 生データをそのままAIに投げるより、列や項目をそろえた入力のほうが実用的な要約になりやすい

- 要約だけで終わらせず、タスク管理ツールまでつなぐと業務に定着しやすい

- 1回の大きな自動化より、小さな面倒を1つずつ消すほうが作りやすい

- メディア運用に限らず、『取得→要約→次アクション化』の形は多くの仕事に転用できる

自分で作るなら？・どう応用できる？

自分で作るなら、次のように組めます。

1. データを取得

- 例: ブログ、SNS、EC、問い合わせ、営業日報、家計、学習記録など

- 方法: Python、Google Sheets、Excel、Zapier、Make、API、CSV出力

2. AIに渡す前に整形

- 日付、件数、カテゴリ、金額、反応数などを1行1レコードで整理

- 文字列だけでなく、表形式で渡せる状態にする

3. AIで処理

- 要約: 何が増えたか、何が減ったか

- 分類: どのカテゴリが強いか

- 抽出: 例外値、重要項目、要確認項目

- 文章化: 週次報告、上司向けメモ、次の打ち手案

- 実装候補: ChatGPT、OpenAI API

4. 保存・出力

- Notionにタスク登録

- Google SheetsやExcelに履歴保存

- Gmailで自分に送信

- SlackやPushoverで通知

5. 人間が確認

- 重要な判断、公開前の文面、金額や顧客情報、例外対応は最終確認する

仕事への応用例

- コンテンツ運用: PV、CTR、滞在時間を取得→AIで伸びた記事の共通点を要約→Notionに次回のネタ案を登録

- 営業管理: 商談メモや受注失注理由を整理→AIで勝ちパターンを要約→Slackに週次レポート送信

- カスタマーサポート: 問い合わせ件名と本文を分類→AIで緊急度と論点を整理→担当者別の対応リストを作成

- 社内報告: 日報や作業ログを集計→AIで週報を生成→Google DocsやNotionに保存

個人利用の応用例

- 家計管理: クレジットカード明細をCSV化→AIで支出カテゴリを要約→毎月の見直し項目をNotionに出力

- 学習記録: 読書メモや英語学習ログを集める→AIで進捗と弱点を要約→次週の学習タスクを作成

- 健康管理: 歩数・睡眠・食事メモを整理→AIで傾向を要約→改善候補をメモ化
